#Päiväkirja

Kouluprojektina tehty pienimuotoinen päiväkirja, johon voit merkitä päivittäin, miten nukuit ja minkälainen mieliala sinulla on.

#Ominaisuudet

-Valitse päivä
-Millainen mielialasi on
-Monta tuntia nukuit
-Lisää merkintä ja selaa

#Käytetyt tekniikat

-HTML
-JavaScript
-CSS
-SGL
